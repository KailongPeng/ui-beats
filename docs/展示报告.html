PART 1 原理 · PN-QRS 不确定性机制 来自论文 · 非本仓库贡献
1.1 · Problem

为什么上臂心电必须先"质检"

医院 12 导联 ECG 信号干净，P/Q/R/S/T 波清晰。但上臂单导联离心脏远、经肌肉骨骼衰减， 叠加运动伪迹与肌电噪声 —— 很多 10 秒窗口根本不可用。若不先筛掉坏窗口， 下游训练/推理会被噪声污染。质量评估必须前置。

V1临床 ECG vs 上臂 ECG 示意图
上：临床导联，P/Q/R/S/T 形态清晰、基线平稳。 下：上臂 CH20，R 峰尚存但 P/T 波微弱，叠加基线漂移（低频起伏）与肌电噪声（高频毛刺）。 同一段时间，下方信号的可读性显著下降 —— 这正是需要不确定性来量化的对象。
1.2 / 1.3 · Two Uncertainties

模型怎么"知道自己不确定"

PN-QRS（名字来自 Positive–Negative）对每帧特征做正变换 φ⁺ 与负变换 φ⁻，产生"乐观/悲观分身"， 再用 MC-Dropout 多次前向。两个分身的分歧给出两种不确定性，物理含义完全不同：

UE
认知不确定性 · Epistemic
"这段到底是不是 ECG？"

粒度：窗口级标量（对 T 帧求均值）。衡量整段信号与训练分布的距离 —— 输入 PPG、心音或纯噪声时分身分歧巨大，UE 飙升。用于 OoD 筛查：整段非 ECG 则丢弃。

UE = (1/T) Στ [ ŷ⁺·log(ŷ⁺/ŷ) + ŷ⁻·log(ŷ⁻/ŷ) ] — 对正负变换前后预测分布求 KL 散度（公式 5）

论文阈值 α = 0.1

UA
偶然不确定性 · Aleatoric
"这一拍清不清楚？"

粒度：帧级序列（T 个值，与时间轴对齐）。衡量每一帧预测的模糊度 —— 某处心拍形态特殊（室早、束支阻滞）时该帧熵高。用于逐拍判定：标记可疑心拍，信号保留。

UA = −[ ŷ⁺·log ŷ⁺ + (1−ŷ⁻)·log(1−ŷ⁻) ] — 每帧相对正负变换的预测熵（公式 6）

论文阈值 β = 0.12 · 取 R 峰前后 7 帧均值

V2 ★不确定性在波形上的物理意义 示意图
顶部：一段含噪声区间的 ECG。中条 U_A（帧级）：在噪声帧与那个形态异常的可疑心拍处变红。 底条 U_E（窗口级）：把整段打成一个标量并广播 —— 噪声窗口整体偏红、干净窗口偏绿。 颜色越红 = 越不确定。两条带分别对应"逐拍可疑"与"整段 OoD"。
1.4 · Algorithm 1

论文推理流程：先筛整段，再标逐拍

V3PN-QRS 推理流程
STEP 1–2
编码 + PN 变换
每导联送入多分支 CNN → 逐帧 logits ŷ；φ⁺/φ⁻ 产生 ŷ⁺ / ŷ⁻
STEP 3–5 · 窗口级
UE 筛 OoD
UE > α → 整段是非 ECG 噪声，丢弃该导联
STEP 6–10 · 多导联
逐帧选最优导联
U = UE+UA，每帧选 U 最小的导联 → R 峰序列
STEP 11–14 · 帧级
UA 标可疑拍
每个 R 峰取前后 7 帧 UA 均值，> β → 标记可疑心拍

UE 认知窗口级标量α = 0.1判断整段是否为 non-ECG（OoD 筛查）

PART 2 创新点 · UI_Beat_share 的贡献 ★ 本仓库原创

以下七项是本仓库在完全不改动 PN-QRS 模型核心（0 行）的前提下， 面向上臂可穿戴场景做出的原创设计。每一项都标注了对应代码位置。

2.1跨域零样本迁移★ 最强创新

随仓库附带的权重 best_model.pt（348 KB）只见过 CPSC2019 临床 ECG （胸导联、干净、500 Hz、静态）。它被直接用于上臂 CH20 可穿戴信号（运动伪迹、肌电、信号弱、非标准电极）， 无 fine-tune、无 domain adaptation、无目标域标注，依然能靠不确定性区分高/低质量窗口。

这反而是更强的学术论点：PN-QRS 的不确定性估计具备跨域泛化能力 —— 原论文只在同域（CPSC→MIT-BIH）评测，从未涉及上臂场景。

2.2单通道质量判据 mean(U_E + U_A)

原版 multi_lead_select 依赖多导联交叉投票决定可信度；上臂只有一路电极，该机制失效。 本仓库改用单通道 mean(U_E + U_A) 作自评估：U_E 反映"模型不确定"，U_A 反映"信号本身糟糕"，相加同时捕捉两者。

关键工程细节：代码对逐帧认知项做了二值化 eu[eu > 0.12] = 10， 于是 mean_uc 的本质变成噪声帧占比的加权计数：

mean_uc ≈ (1/T) Στ [ 10·𝟙(euτ > 0.12) + auτ ] 干净窗口 ≈ 0.1–0.5 · 电极脱落 → ≈ 10 · 故意制造悬殊双峰
V5mean_uc 如何形成双峰示意图
逐帧 eu 曲线（左）→ 经 eu>0.12 打成 10 的二值化（中）→ 对全窗求均值 → 干净窗与噪声窗在直方图上形成悬殊双峰（右）。 正是这种二值化放大效应，让后续 Otsu 阈值可信。
⚠️ 诚实标注（critical reading）：这套 mean_uc 是工程改写，并非论文 Algorithm 1 的原始定义。 论文中 U_E 是窗口级标量（与 α=0.1 比较）、U_A 是帧级序列（与 β=0.12 比较），两者从不合并为质量分数； 代码把 β=0.12 挪用于 eu 的逐帧二值化。功能等价（噪声越多分数越高），但实现路径与论文不同。
参考 pipeline/extract_quality_segments.py:161-179（uncertain_est / en_est / mi_est 组合）
2.3Otsu 自适应阈值 · 解决域漂移

上臂 ECG 的 mean_uc 分布整体高于医院 12 导联（肌电、运动伪迹）。 原版固定阈值 UC_THR=1.0 直接套用会把 90% 数据判成 bad。 本仓库用一维 Otsu 二值化自动最大化"好/坏窗口"的组间方差，阈值随数据分布自适应。

V6Otsu 在双峰直方图上的最优分割示意图
mean_uc 双峰直方图。竖线为 Otsu 自动求得的阈值：左侧绿色判 good、右侧红色判 bad。 固定阈值 1.0（灰色虚线）在上臂数据上会偏到左峰内，误杀大量好窗口。
pipeline/extract_quality_segments.py:85-114（otsu_threshold，O(n) 累积和实现）
2.4两阶段全局池化 · 统一跨被试标尺

每段 30 秒短录制只有 3~4 个滑窗，单文件做 Otsu 样本太少、阈值不稳。本仓库改为两阶段： 先全量推理把所有窗口的 uc 池化到一起，对全局求一个 Otsu 阈值，再回填到每个窗口判定。

所有 CSV 跑推理 → 收集每个滑窗的 mean_uc → 汇入全局池
GLOBAL
全局 Otsu
对 pooled uc 计算单一阈值 → 跨被试 uc 标尺统一
PASS · 2
回填 + 判定
逐窗 is_good 判定 → 保存 NPZ 片段 + 可视化
pipeline/extract_quality_segments.py:770-834（_worker_infer + _worker_process）
2.5双重校验 · 不确定性 + 心拍数合理性

仅靠 uc 阈值可能误判 —— 信号嘈杂到模型"自信地预测很多假 R 峰"时 uc 反而低。 本仓库增加生理合理性校验：10 秒内心拍数须落在 [5, 25]（≈30–150 bpm）。两条件同时满足才算 good。

V8双重校验逻辑
mean_uc ≤ uc_thr
不确定性低于 Otsu 阈值
5 ≤ n_beats ≤ 25
心拍数生理合理（≈30–150 bpm）
AND
is_good = True
该 10 秒片段保存为 NPZ
pipeline/extract_quality_segments.py:47-48, 184-188（BEAT_MIN=5, BEAT_MAX=25）
2.6活动级汇总 · 哪些动作最易出伪迹

本仓库自动从目录路径提取 被试 × 活动 维度，按活动聚合统计 good_ratio。 实测：慢走、站立坐下 的 good_ratio 最低，符合"动作越大、运动伪迹越多"的生理直觉。

2.8 · Real-World Validation

实测：质量筛选带来的下游收益 实测数据 · 非示意

在 3 名被试的上臂实测数据上，用一个简单下游模型衡量表现（Pearson 相关系数）。 对比筛选前（全部窗口）与筛选后（仅保留高质量片段）： 3/3 被试相关系数全部提升，subject3 提升最大（0.675 → 0.844，+25%）。 这是质量筛选有效性的直接证据 —— 把 Part 2 的"质量判据"从机制论证落到了可量化的下游收益。

每位被试一组：筛选前（琥珀，全部窗口）vs 筛选后（绿，仅高质量片段；subject2/3 有两个分段）。 柱顶为实际数值、绿字为相对筛选前的提升量。y 轴自 0.6 起以放大差异，具体数值以柱顶标注为准。
为什么会提升：质量筛选剔除了运动伪迹 / 肌电污染的窗口，下游模型只在干净片段上拟合， 相关系数随之上升。提升幅度与被试原始信号质量相关 —— subject3 筛选前最低（0.675）、提升空间最大（+25%）； subject1 本就较干净（0.887），提升较小（+0.038）但仍为正。
